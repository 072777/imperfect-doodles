# Imperfect Doodles — Prompt Examples

## 01 — Everyday Icons

```text
#ImperfectDoodles
把 Home、Message、Calendar、Shopping Bag 四个常用 icon 改成黑白手绘版本。
保留原本功能识别，只让线条微微歪、比例略不标准，像同一个人随手画出来的。
不要加颜色，不要变成卡通插画。
```

## 02 — Relaxed UI

```text
Use Imperfect Doodles skill.
Keep the existing product hierarchy and spacing.
Redraw only the icons, dividers, small illustration, and selected borders.
Use a warm cream background, black hand-drawn strokes, and lots of breathing room.
Make it relaxed, not messy.
```

## 03 — Remove the AI Look

```text
#ImperfectDoodles
这个页面太 AI-clean 了。
不要重做 UX，只调整视觉性格：
线条歪一点、图标不要完全对称、重复元素不要一模一样、留白更多。
整体保持米白 + 黑色线稿，少量浅蓝点缀即可。
```

## 04 — Wallpaper

```text
#ImperfectDoodles
做一张 9:16 手机壁纸。
米白背景，一个垂耳小狗趴在桌面旁边，旁边有一个杯子和一个小音符。
黑色随手线稿，比例略奇怪，大量留白。
文字：good things take time.
整体松弛，不要做成海报。
```

## 05 — Empty State

```text
Use Imperfect Doodles skill to create an empty state.
A tiny person sits beside an oversized empty notebook.
Keep the character awkward and simple, with uneven lines and minimal facial detail.
Do not add lots of decoration.
```

## 06 — Poster

```text
#ImperfectDoodles
做一个极简活动海报。
一个大标题 + 一个简单手绘主体 + 2 个以内辅助 doodle。
不要贴纸拼贴，不要做旧，不要堆满。
重点是松弛和人手感。
```
