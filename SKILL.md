# Imperfect Doodles

## Core Idea

Too correct is the most AI-looking choice.

Human-made visuals often contain tiny signs of the hand:

- lines that wobble
- proportions that are slightly strange
- repeated shapes that are not identical
- spacing that is a little uneven
- tiny mistakes that remain visible

These imperfections should not be corrected away.

They are what make the visual feel relaxed, human, and alive.

The goal is not to make things ugly or messy.

The goal is:

**Relaxed feeling + clear structure + imperfect execution**

Or more simply:

**Don't make it messy. Make it human.**

---

# 1. Relaxed Feeling Comes First

Before adding imperfection, establish a calm and loose feeling.

Prefer:

- generous empty space
- simple composition
- low visual pressure
- few visual elements
- soft rhythm
- slightly awkward but charming placement
- minimal decoration

Avoid:

- over-designed layouts
- dense collage composition
- filling every empty area
- excessive stickers or decorations
- dramatic visual effects

The visual should feel effortless.

It should look like someone drew it naturally,
not like someone tried very hard to imitate hand drawing.

---

# 2. Never Draw a Perfect Line

Avoid perfectly straight or mechanically smooth vector lines.

Lines may:

- wobble slightly
- bend unexpectedly
- vary subtly in thickness
- stop a little early or late
- overshoot corners
- contain small directional changes
- overlap slightly

A circle should not be mathematically circular.

A rectangle should not have four perfectly parallel edges.

A heart should not be symmetrical.

A divider should not look ruler-straight.

Keep the imperfection visible but restrained.

---

# 2.1 Single-Stroke Outline Rule

This rule is critical, especially for image-to-image transformation.

Each visible edge should be represented by **one single contour only**.

Do not preserve a clean vector contour and then add another loose hand-drawn contour on top of it.
Do not create a trace-over effect.
Do not use doubled outlines, parallel outlines, ghost outlines, offset sketch lines, or repeated border tracing to fake a handmade feeling.

A hand-drawn look should come from the **single contour itself** being imperfect:

- slight wobble
- uneven pressure
- minor asymmetry
- small positional error
- awkward proportion

It should NOT come from adding a second contour.

Hard rule:

**One form = one contour.**  
**One edge = one stroke.**  
**Redraw, don't overlay.**

If emphasis is needed, vary stroke weight slightly instead of adding a second parallel line.

The final result should feel like a person drew the shape once,
not like the model traced the same edge twice.

---

# 3. Awkward Proportions Are Good

Objects should feel intuitively drawn rather than geometrically constructed.

Allow:

- heads slightly too large
- arms slightly too short
- uneven flower petals
- asymmetric icons
- objects leaning a little
- uneven gaps
- naive perspective
- slightly strange silhouettes

Important:

**Awkward does not mean broken.**

The object should still be immediately recognizable.

---

# 4. Use Fewer Strokes

Whenever possible, reduce an object to the fewest useful strokes.

Prefer:

- primitive contours
- simple symbols
- one-stroke gestures
- minimal details
- naive shapes

Avoid:

- polished Bézier curves
- excessive vector nodes
- detailed rendering
- perfect outlines
- unnecessary decoration

Ask:

Could a person draw this quickly in a notebook?

If not, simplify it.

---

# 5. Repetition Should Never Be Identical

Repeated elements should feel related,
but not duplicated.

If drawing several stars, flowers, buttons, or icons,
slightly vary:

- angle
- width
- height
- spacing
- line shape
- proportions

The result should feel like the same person drew each one separately.

Do not copy-paste the same imperfection.

---

# 6. Imperfection Budget

Do not apply every imperfection at once.

For each object,
choose only 2–4 visible imperfection behaviors.

Example: flower

- uneven petals
- slightly crooked stem
- off-center middle

That is enough.

Do not also add random rotation, broken strokes, noise, texture,
multiple colors, and distorted perspective at the same time.

Imperfection should feel selective.

---

# 7. Icon Language

Icons are one of the most important use cases for this skill.

Prefer everyday icons such as:

- home
- message
- calendar
- shopping bag
- search
- heart
- camera
- bell
- weather
- settings
- phone
- folder

Use:

- monochrome black or charcoal line work by default
- simple recognizable silhouettes
- slightly uneven strokes
- subtle asymmetry
- imperfect corners
- naive geometry

The icon set should feel like the same person drew all icons.

Maintain consistency in:

- approximate stroke weight
- visual size
- simplicity
- emotional tone

Allow slight differences in:

- proportions
- angles
- curves
- spacing

Do not make icons mathematically perfect.

Do not make them decorative at the expense of recognition.

---

# 8. Character and Illustration Language

Characters should feel simple, awkward, and relaxed.

Recommended traits:

- oversized head or body feature
- simplified limbs
- minimal face
- slightly uneven eyes
- strange but readable posture
- minimal shading
- simple emotional expression

Illustrations should feel like notebook doodles.

Examples:

- a floppy-eared dog resting beside a mug
- a tiny person sitting on a sofa
- a flower with uneven petals
- a bird with slightly wrong proportions
- a cloud drawn in one loose contour

Avoid:

- polished mascot design
- Pixar-like rendering
- anime anatomy
- highly detailed shading
- overly cute children's-book styling

Naive does not automatically mean childish.

---

# 9. Typography

Typography should support the handmade world.

Prefer:

- simple handwriting
- irregular handwritten lettering
- subtle baseline variation
- slightly uneven spacing

Avoid:

- polished calligraphy
- decorative scripts
- overly consistent fake-handwriting fonts
- long paragraphs in hard-to-read handwriting

For UI,
keep body text readable and use handmade lettering selectively.

---

# 10. Layout

Keep the structure clear.

Prefer:

- one dominant focal point
- generous empty space
- simple grouping
- low visual density
- calm spacing

Small irregularities are allowed:

- an icon sits slightly lower
- a label is a little off-center
- a border is not perfectly square
- a doodle breaks the grid slightly

Do not:

- randomly rotate every block
- destroy hierarchy
- overlap important information
- make controls hard to scan

Remember:

**Imperfect drawing ≠ imperfect usability.**

---

# 11. Color

Default visual direction:

- warm off-white / cream background
- black or charcoal line work
- optional pale blue accent

Use color sparingly.

Prefer flat color.

Avoid:

- glossy gradients
- neon colors
- metallic effects
- heavy shadows
- excessive color variation
- generic AI glow

Color should support the relaxed feeling,
not compete with the drawing.

---

# 12. Texture

Texture is optional.

A subtle paper feel is acceptable,
but handmade feeling should come mainly from:

- line behavior
- proportion
- spacing
- human error

Do not use texture as a shortcut.

Avoid excessive:

- grain
- scratches
- torn paper
- vintage effects
- fake notebook overlays

---

# 13. UI Transformation Rules

When converting an existing interface into Imperfect Doodles:

## Keep

- information architecture
- navigation logic
- content hierarchy
- interaction patterns
- readability
- accessibility
- button positions

## Transform

- icons
- dividers
- illustration
- selected borders
- decorative shapes
- empty states
- selected display typography

Do not redesign the whole UX.

Change the visual personality,
not the underlying function.

---

# 13.1 Image-to-Image Conversion Rule

When transforming an existing image, icon, illustration, or UI into Imperfect Doodles:

- preserve the original structure and meaning
- **replace** precise vector edges with single imperfect hand-drawn contours
- simplify contours when needed
- keep one visible line per edge

Do not:

- keep the original vector outline and add a sketch line on top
- create two parallel contour lines
- create ghosted or offset outlines
- simulate sketchiness through repeated tracing
- leave both the original clean line and the handmade line visible

The transformation should look **redrawn**, not traced over.

**Hand-drawn feeling must come from one imperfect contour, not from a second contour.**

---

# 14. Before / After Logic

## Before

- clean geometric icons
- perfect curves
- strict repetition
- polished vector shapes
- mathematically balanced spacing

## After

- same function
- same meaning
- same hierarchy
- slightly wobbly lines
- imperfect proportions
- handmade contours
- small inconsistencies

The transformation should feel like:

**digital structure drawn by a relaxed human hand.**

---

# 15. Common Failure Modes

## Failure 1 — Too messy

Problem:
The AI interprets imperfect as chaos.

Fix:
Restore spacing and hierarchy.
Keep imperfection only in selected elements.

## Failure 2 — Too polished

Problem:
The result is still a perfect vector system with a handwriting font.

Fix:
Introduce real line irregularity and non-identical shapes.

## Failure 3 — Too childish

Problem:
The style turns into children's illustration.

Fix:
Reduce decoration, facial detail, and cuteness.
Use more neutral composition.

## Failure 4 — Too much texture

Problem:
Paper grain is doing all the work.

Fix:
Remove most texture and rely on lines and proportion.

## Failure 5 — Too many doodles

Problem:
Every empty area gets filled.

Fix:
Delete at least 30–50% of decorative elements.
Restore breathing room.

## Failure 6 — Perfect icon set

Problem:
Icons still look like a polished library.

Fix:
Redraw each icon separately with subtle differences,
while keeping overall consistency.

## Failure 7 — Double-line outline / ghost tracing

Problem:
The model keeps the original clean contour, then adds another sketchy line around or beside it.
Some models also use two parallel contour lines to imitate sketchiness.

Why this is wrong:
It creates a duplicated, ghosted, traced-over appearance instead of a relaxed human-drawn line.

Fix:
Use only one visible contour per shape.
Redraw the original contour itself as a slightly imperfect single stroke.

Do not stack a sketch line on top of a vector line.

**Replace the line — do not decorate the line.**

# Generation Process

When creating an Imperfect Doodles design:

1. Establish a calm, simple composition.
2. Protect the hierarchy and function.
3. Remove unnecessary decoration.
4. Reduce objects to simple recognizable forms.
5. Choose where handmade personality should appear.
6. Set an imperfection budget for each object.
7. Draw with minimal strokes.
8. Break geometric perfection selectively.
9. Vary repeated objects slightly.
10. Check that the result still feels relaxed.
11. Restore empty space if the design feels busy.
12. Stop before the design becomes overworked.

---

# Final Quality Check

Before finishing, ask:

1. Does the visual feel relaxed first?
2. Is there enough empty space?
3. Are any lines suspiciously perfect?
4. Are repeated elements completely identical?
5. Are proportions slightly awkward but still readable?
6. Could a person realistically draw this by hand?
7. Did I accidentally turn imperfect into messy?
8. Did I add too many decorations?
9. Do all icons feel drawn by the same hand?
10. Is the UI still usable?
11. Does the result feel human rather than AI-clean?
12. Did I stop before over-designing it?

If everything looks too correct,
introduce one small human mistake.

If everything looks chaotic,
restore structure and breathing room — not polish.

---

# Final Principle

Do not make the design intentionally bad.

Make it intentionally human.

**Too correct is the most AI-looking choice.**
